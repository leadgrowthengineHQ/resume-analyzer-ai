# Resume Analyzer AI

A simple web app to upload and analyze resumes. Currently stores resumes and displays basic information. OpenAI API integration is planned for future updates.

## Features
- Upload resume PDFs
- Display basic resume content

## Tech Stack
- Node.js (backend)
- Express
- Vanilla HTML, CSS, JS (frontend)
- PostgreSQL (optional/future)

## Setup
1. Clone the repo:
   ```bash
   git clone https://github.com/your-username/resume-analyzer-ai.git
2. Navigate to backend:

cd backend


3. Install dependencies:

npm install


4. Start server:

npm start


5. Open frontend/index.html in browser.
